# Agent Template

Шаблон для старта любого проекта (Android/iOS/Spring/Node/Python, монорепо, база знаний Obsidian…),
в котором работают AI-агенты: Claude Code, Codex, Cursor, Copilot, Gemini CLI, Aider, Windsurf.

Цель: агент в новом чате **без контекста** быстро ориентируется, читает только нужное
и сам поддерживает документацию проекта в актуальном и компактном виде.

## Как начать новый проект

1. `Use this template` на GitHub (или `git clone` + удалить `.git`).
2. Откройте проект в любом агенте и напишите: «Инициализируй проект: <что строим>».
3. Агент увидит `status: uninitialized` в `.agents/STATE.md` и выполнит `.agents/playbooks/bootstrap.md`.

## Как это устроено

```
AGENTS.md                 ← единая точка входа (стандарт agents.md), ≤120 строк
CLAUDE.md, GEMINI.md,     ← адаптеры: только ссылка на AGENTS.md
.github/copilot-instructions.md, .cursor/rules/agents.mdc
.agents/
  STATE.md                ← что за проект, команды, текущий фокус (перезаписывается)
  MAP.md                  ← карта: одна строка на модуль → его AGENTS.md
  DECISIONS.md            ← журнал решений (append-only, одна строка на решение)
  ignore.md               ← что агентам никогда не читать
  playbooks/              ← процедуры: bootstrap, new-module, finish-task, maintenance
  rules/                  ← тематические правила, грузятся по триггеру
  templates/              ← шаблоны модульного AGENTS.md, правила, ADR
<module>/AGENTS.md        ← локальные правила модуля, ≤60 строк, читаются только при работе в нём
scripts/agent-lint.sh     ← проверка бюджетов строк и битых ссылок в MAP
```

## Принципы (best practices)

| Принцип | Зачем |
|---|---|
| **Progressive disclosure**: корень → MAP → модуль → код | Постоянный контекст не растёт с проектом |
| **Одна точка правды** (AGENTS.md), адаптеры только ссылаются | Нет рассинхрона между агентами |
| **Иерархия = локальность**: знание кладётся в самый глубокий подходящий файл | Агент не читает чужие правила |
| **Бюджеты строк** + `agent-lint` | Документы не разбухают |
| **STATE перезаписывается, DECISIONS дописывается** | Короткое «сейчас» + сохранённое «почему» |
| **Playbooks по триггеру**, а не в корне | Инструкции грузятся только когда нужны |
| **ignore-списки** (lock-файлы, build, бинарники) | Ноль токенов на мусор |
| **Самообслуживание**: `finish-task` после каждой задачи, `maintenance` периодически | Проект развивается в новых чатах без потерь |
| **Агентские документы на английском** | Кириллица ≈ в 2–3 раза дороже в токенах |

## Проверка

```bash
sh scripts/agent-lint.sh
```
